QUICK START
-----------
1. Clone:   git clone https://github.com/DonkRonk17/MCPBridge.git
2. Register: python mcpbridge.py register --all
3. Serve:   python mcpbridge.py serve
4. Verify:  python mcpbridge.py status

================================================================================
CORE COMMANDS
--------------------------------------------------------------------------------

STATUS & INFO:
  python mcpbridge.py --version
  python mcpbridge.py --help
  python mcpbridge.py status

REGISTER AGENTS:
  python mcpbridge.py register --all
  python mcpbridge.py register --agent ATLAS
  python mcpbridge.py register --agent FORGE
  python mcpbridge.py register --agent CLIO
  python mcpbridge.py register --agent NEXUS
  python mcpbridge.py register --agent BOLT

LIST AGENTS:
  python mcpbridge.py list

GET AGENT CARD:
  python mcpbridge.py card --agent ATLAS
  python mcpbridge.py card --agent FORGE > forge_card.json

START SERVERS:
  python mcpbridge.py serve
  python mcpbridge.py serve --mcp-port 9765 --a2a-port 9766
  python mcpbridge.py serve --verbose
  python mcpbridge.py serve --log D:\BEACON_HQ\bridge.log

DISCOVER EXTERNAL AGENTS:
  python mcpbridge.py discover --url http://agent.example.com

DELEGATE TASKS:
  python mcpbridge.py delegate --url http://agent.example.com --message "Task here"

TASK HISTORY:
  python mcpbridge.py tasks
  python mcpbridge.py tasks --agent ATLAS
  python mcpbridge.py tasks --limit 100

================================================================================
GLOBAL OPTIONS
--------------------------------------------------------------------------------
  --db PATH         Registry database path (default: ~/.mcpbridge/registry.db)
  --mcp-port PORT   MCP server port       (default: 8765)
  --a2a-port PORT   A2A server port       (default: 8766)
  --host HOST       Host for agent URLs   (default: localhost)
  --verbose, -v     Enable debug logging

================================================================================
PROTOCOL ENDPOINTS (when server running)
--------------------------------------------------------------------------------

MCP ENDPOINTS (Port 8765):
  POST http://localhost:8765/mcp     JSON-RPC 2.0 endpoint
  GET  http://localhost:8765/health  Health check

A2A ENDPOINTS (Port 8766):
  GET  /.well-known/agent.json       A2A standard discovery
  GET  /agents                       List all agents
  GET  /agents/{NAME}                Get specific agent card
  POST /tasks                        Submit task to agent
  GET  /tasks/{id}                   Get task status

================================================================================
MCP JSON-RPC METHODS
--------------------------------------------------------------------------------
  initialize       {"clientInfo": {"name": "MyClient", "version": "1.0"}}
  tools/list       {}
  tools/call       {"name": "tool_name", "arguments": {...}}
  resources/list   {}
  resources/read   {"uri": "bch://atlas/config"}
  prompts/list     {}
  prompts/get      {"name": "prompt_name", "arguments": {...}}

EXAMPLE MCP REQUEST:
  curl -X POST http://localhost:8765/mcp \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'

PYTHON API - QUICK REFERENCE
--------------------------------------------------------------------------------

IMPORT:
  from mcpbridge import ProtocolBridge, AgentCard, MCPTool, MCPResource
  from mcpbridge import AgentCardGenerator, CapabilityRegistry, A2AClientModule
  from mcpbridge import MCPProtocol, MCPStdioAdapter, A2ATask

INIT BRIDGE:
  bridge = ProtocolBridge()
  bridge = ProtocolBridge(db_path=Path("custom.db"), mcp_port=8765, a2a_port=8766)

REGISTER AGENTS:
  card = bridge.register_bch_agent("ATLAS", "Description")
  card = bridge.register_bch_agent("FORGE", "Description", tools=[tool1])

GET MCP HANDLER:
  mcp = bridge.get_mcp_handler("ATLAS")
  mcp.register_tool_handler("tool_name", lambda args: "result")
  mcp.register_resource_handler("uri://path", lambda: "content")

START / STOP SERVERS:
  bridge.start_servers()    # Background threads
  bridge.stop_servers()     # Graceful shutdown

DISCOVER EXTERNAL:
  card = bridge.discover_external_agent("http://agent.url")

DELEGATE TASK:
  task = bridge.delegate_to_external("http://agent.url", "Do this task")
  print(task.task_id, task.status)

STATUS:
  status = bridge.status()
  # Keys: bridge_version, mcp_port, a2a_port, registered_agents, ...

================================================================================
TROUBLESHOOTING
--------------------------------------------------------------------------------

Port in use:
  netstat -an | findstr 8765           (Windows)
  lsof -i :8765                        (Linux/macOS)
  → Use: --mcp-port 9765 --a2a-port 9766

No agents registered:
  python mcpbridge.py status           (check count)
  python mcpbridge.py register --all   (fix it)

A2A discovery fails:
  → Check agent exposes /.well-known/agent.json
  → Verify network access to agent URL
  → Check agent implements A2A spec

MCP client can't connect:
  curl http://localhost:8765/health    (verify running)
  → Check port not blocked by firewall
  → Verify mcpbridge serve is running

Database locked:
  → Only one serve instance at a time
  → Kill old: Get-Process python (Windows) or ps aux | grep python

Windows encoding:
  [Console]::OutputEncoding = [System.Text.Encoding]::UTF8
  python mcpbridge.py ...
